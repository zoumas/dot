# ghostty

Terminal emulator configuration.

## Contents

`config` sets:

- `theme = Gruvbox Material Dark` — matches the rest of the desktop
- `font-size = 15`
- `confirm-close-surface = false` — no confirmation dialog on close
- `mouse-hide-while-typing = true`

Font family is left at Ghostty's own default (JetBrains Mono Nerd Font).

## Dependencies

```sh
sudo pacman -S ghostty
```
